# مساعد أراضي بيت الوطن - المرحلة الحادية عشر (غير رسمي)

شات بوت بسيط بالعربي بيجاوب على أسئلة عن أسعار واشتراطات أراضي مشروع
"بيت الوطن" - المرحلة الحادية عشر (المصريين بالخارج)، مبني بـ [Streamlit](https://streamlit.io).

## ⚠️ إخلاء مسؤولية

- **هذا المشروع غير رسمي وغير تابع** لهيئة المجتمعات العمرانية الجديدة أو
  وزارة الإسكان المصرية.
- كل البيانات منقولة من **الكراسة الرسمية المنشورة** من الهيئة:
  <https://lands.nuca.gov.eg/Files/Handbook.pdf> (يونيو 2026).
- الأسعار والشروط عرضة للتغيير من الجهة الرسمية في أي وقت. **راجع دائمًا
  الكراسة الرسمية والقنوات الرسمية للهيئة قبل اتخاذ أي قرار مالي أو تحويل
  أي مبلغ.**
- **بيانات أرقام القطع الفردية الدقيقة (رقم كل قطعة ومساحتها) غير متوفرة**
  في هذا الإصدار — القسم المخصص لها (`VERIFIED_PLOTS` في `app.py`) فارغ
  عمدًا. حاولنا استخراجها آليًا من خرائط مصورة وتبين إن دقة الاستخراج غير
  كافية للثقة بها في قرار مالي، فتم استبعادها بدل ما تُنشر بيانات فيها
  احتمال خطأ.

## تشغيل المشروع محليًا

```bash
pip install -r requirements.txt
streamlit run app.py
```

## المحتوى

- `app.py` — الكود الكامل (شات بوت + حاسبة سداد + جدول أسعار).
- كل الأرقام (الأسعار، نسب التميز، بدائل السداد، بيانات التحويل البنكي)
  موثقة داخل الكود مع رقم الصفحة في الكراسة الرسمية اللي جاية منها.

## المساهمة ببيانات قطع فردية

لو عندك رقم قطعة ومساحتها متأكد منه 100% من مصدر رسمي (الكراسة، أو
موقع الهيئة، أو محضر تسليم رسمي)، تقدر تضيفه في `VERIFIED_PLOTS` داخل
`app.py` مع ذكر مصدر التأكيد. **من فضلك متضفش أرقام مش متأكد منها.**

## الترخيص

استخدم الكود بحرية، بس البيانات نفسها ملك الجهة الرسمية ولازم دايمًا
تتأكد منها من مصدرها قبل أي استخدام مالي.
